## 1. 概述

`rks_extra` 是一个服务器安全数据包，提供三大核心功能：

| 功能 | 说明 |
|------|------|
| **OP 泄露检测** | 自动检测非管理员获得 OP 权限 / 创造模式 / 命令方块 |
| **爆炸防护** | 防爆区自动清除 TNT；主世界禁止末影水晶和 TNT 矿车 |
| **TNT 限制** | 每人每分钟限放 1 个 TNT，超量自动没收并归还 |

---

## 2. 管理员身份配置

数据包通过 **`player` 标签** 识别管理员。拥有此标签的玩家会收到所有警报通知。

```mcfunction
# 将自己设为管理员
/tag @s add player

# 将指定玩家设为管理员
/tag <玩家名> add player

# 移除管理员的警报接收权限
/tag <玩家名> remove player
```

> ⚠️ **重要**：所有警报消息仅发送给带有 `player` 标签的玩家。服务器上线后务必先给自己打上此标签。

## 3. 功能一：OP 泄露检测

### 检测机制（每 tick 自动执行）

系统持续检测以下异常状态，**未携带 `player` 标签** 的玩家若符合任一条件即被标记：

| 检测条件 | 说明 |
|----------|------|
| 游戏模式为创造 | 非管理员不应有创造模式 |
| 游戏模式为旁观 | 非管理员不应有旁观模式 |
| `mayfly` 能力开启 | 非管理员不应有飞行权限 |
| `Invulnerable` 标签 | 非管理员不应无敌 |
| 背包含命令方块 | 非管理员不应获取命令方块 |

### 警报行为

- 被标记的玩家 `good` 分数被设为 1
- **每 5 秒**（100 tick），若存在被标记玩家，向全体管理员广播：
  ```
  [op泄露警报]
  嫌疑玩家: <玩家名>
  ```

### 管理员操作

```mcfunction
# 查看被标记的玩家
/scoreboard players list @a[scores={good=1}]

# 手动清除某玩家的标记（确认其合法后）
/scoreboard players set <玩家名> good 0
```

## 4. 功能二：爆炸防护

### 4.1 防爆区管理（可热编辑）

防爆区是服务器中 **自动清除 TNT 实体** 的安全区域。区域列表存储在命令存储器中，**游戏内即时编辑，无需 `/reload`**。

#### 默认防爆区

| # | 区域名称 | 起点 (x, y, z) | 跨度 (dx, dy, dz) |
|---|----------|----------------|---------------------|
| 0 | 雪豹小镇 | (-1100, -64, 0) | (700, 384, 600) |
| 1 | 雪豹小镇旁广场 | (-250, -64, 400) | (250, 384, 250) |
| 2 | boss2 基地 | (65, -64, -600) | (300, 384, 300) |
| 3 | 血小板大学城 | (-660, -64, -1400) | (1440, 384, 400) |
| 4 | beluga 基地 | (1600, -64, -1750) | (340, 384, 160) |

#### 管理员命令

```mcfunction
# 📋 查看所有防爆区（含序号）
/function rks_extra:tnt_free_area/list

# ➕ 添加防爆区
#    (x,y,z)=最小角坐标  (dx,dy,dz)=区域跨度
/function rks_extra:tnt_free_area/add {x:<X>,y:<Y>,z:<Z>,dx:<宽>,dy:<高>,dz:<深>}

# ➖ 按序号删除（序号从0开始，先执行 list 查看）
/function rks_extra:tnt_free_area/remove {index:<序号>}

# 🗑️ 清空所有防爆区
/function rks_extra:tnt_free_area/clear

# 🔄 恢复默认防爆区（清空后可重新初始化）
/function rks_extra:tnt_free_area/init
```

#### 添加防爆区示例

```mcfunction
# 保护从 (-500, -64, 300) 到 (0, 320, 800) 的矩形区域
# dx = 0-(-500) = 500, dy = 320-(-64) = 384, dz = 800-300 = 500
/function rks_extra:tnt_free_area/add {x:-500,y:-64,z:300,dx:500,dy:384,dz:500}
```

> 💡 **技巧**：使用 F3 屏幕获取坐标，站在两个对角处分别记录，然后用大坐标减小坐标算出 dx/dy/dz。

#### 注意事项

- 添加后 **立即生效**，无需 `/reload`
- `/reload` **不会** 覆盖已编辑的区域（已做持久化保护）
- 区域之间的 TNT 清理相互独立，可以重叠
- 性能：实测 5 个区域每 tick < 0.1ms，100 个区域约需 1-2ms

### 4.2 末影水晶 / TNT 矿车检测

**主世界** 中禁止放置末影水晶和 TNT 矿车。

#### 检测机制（每 tick 自动执行）

- 检测主世界中所有 `end_crystal` 和 `tnt_minecart` 实体
- 若其 **8 格内有玩家** 且该玩家 **未携带 `explosive_trusted` 标签**：
  - 该玩家 `explosive_suspicious` 分数 +1
- 每 tick **自动杀死** 主世界中所有末影水晶和 TNT 矿车
- **每 5 秒**（100 tick），若有可疑玩家，向全体管理员广播：
  ```
  [防爆警报]
  有人试图在主世界放置末影水晶/TNT矿车！
  嫌疑玩家: <玩家名>
  ```

#### 给予信任

对可信玩家（如建筑需要）可添加 `explosive_trusted` 标签跳过检测：

```mcfunction
/tag <玩家名> add explosive_trusted
/tag <玩家名> remove explosive_trusted
```

## 5. 功能三：TNT 使用限制

### 规则

| 限制 | 值 |
|------|-----|
| 每人每分钟最多放置 | **1 个** TNT |
| 重置周期 | **60 秒**（1200 tick） |
| 超额处理 | 没收并归还 |

### 行为流程

```
玩家放置 TNT
  │
  ├─ 第1个 → 广播通知管理员 + 温馨提示"每分钟只能放1个"
  │
  └─ 第2个及以上 →
        ├─ 立即用空气替换该 TNT（17×17×17 范围）
        ├─ 向玩家发送警告
        ├─ 2 tick 后自动归还 1 个 TNT
        └─ 广播通知管理员
```

### 周期重置

- 每 60 秒自动重置所有玩家的 TNT 计数
- 被限制的玩家收到提示：`【温馨提示】TNT限制已重置`

### 信任白名单

带有 `explosive_trusted` 标签的玩家 **不受 TNT 数量限制**：

```mcfunction
/tag <玩家名> add explosive_trusted
```

## 6. 信任标签说明

| 标签 | 作用 | 适用场景 |
|------|------|----------|
| `player` | 接收所有安全警报 | **服务器管理员** |
| `explosive_trusted` | 绕过 TNT 限制 + 绕过水晶/矿车检测 | 信任的建筑玩家、OP |

```mcfunction
# 查看某玩家的所有标签
/data get entity <玩家名> Tags

# 批量添加标签
/tag @a[team=admin] add player
```

## 7. 命令速查表

### 防爆区管理

| 操作 | 命令 |
|------|------|
| 查看所有防爆区 | `/function rks_extra:tnt_free_area/list` |
| 添加防爆区 | `/function rks_extra:tnt_free_area/add {x:,y:,z:,dx:,dy:,dz:}` |
| 按序号删除 | `/function rks_extra:tnt_free_area/remove {index:}` |
| 清空全部 | `/function rks_extra:tnt_free_area/clear` |
| 恢复默认 | `/function rks_extra:tnt_free_area/init` |

### 标签管理

| 操作 | 命令 |
|------|------|
| 设为管理员 | `/tag <玩家> add player` |
| 设为爆炸信任 | `/tag <玩家> add explosive_trusted` |
| 移除标签 | `/tag <玩家> remove <标签>` |

### 状态查询

| 操作 | 命令 |
|------|------|
| 查看 OP 泄露嫌疑 | `/scoreboard players list @a[scores={good=1}]` |
| 清除嫌疑标记 | `/scoreboard players set <玩家> good 0` |
| 查看 TNT 计数 | `/scoreboard players get <玩家> tnt_count` |
| 查看可疑爆炸玩家 | `/scoreboard players list @a[scores={explosive_suspicious=1..}]` |
| 重置某玩家 TNT 计数 | `/scoreboard players set <玩家> tnt_count 0` |

### 紧急操作

| 场景 | 命令 |
|------|------|
| 手动重置全局 TNT 周期 | `/function rks_extra:tnt_off` |
| 查看防爆区原始数据 | `/data get storage rks_extra:storage tnt_free.areas` |
